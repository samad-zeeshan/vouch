01 · How it works

Two layers. The code always wins.

Numbers are checked by code

Money, percentages, years and counts are pulled from the draft with exact positions and compared in code. An exact match is green. Up to 25 percent above the sheet is rounded up. Years must match exactly. A number that clashes with a labelled fact goes red. Code cannot hallucinate.

Prose is checked by the model

Names, titles, places and boasts go to DeepSeek with the fact sheet and nothing else. A supported verdict must cite a fact that exists, and the span it quotes must be found in the draft, or the claim is downgraded and the page says so.

Failure never looks like a pass

If the model has an opinion about a span the code already judged, the model loses. If the model times out, refuses or returns broken JSON, the numbers still show, a banner says prose was not checked, and Approve stays locked.

Precision Recall

Recall on contradicted claims is the number that matters most: a missed lie is the one unforgivable error, so the prompt was tuned until it reached 100 and the cost landed on precision, where a human still reviews every flag. Reproduce with uv run python -m evals.

03 · Scope

Small on purpose.

In

  • One page. Two boxes, a Check button, a gated Approve button.
  • Deterministic checking of numbers, money, percentages and years.
  • Model-checked prose with strict limits on what it may claim.
  • Inline highlights with a one-line reason on hover.
  • A shipped sample with exactly one planted error per state.

Out, deliberately

  • No accounts, saving, history or file upload.
  • No web lookups. The fact sheet is the only source of truth.
  • No rewriting. Vouch reports, the human edits.
  • Quote checking ships dark behind CHECK_QUOTES, off by default.
04 · Spec first

Written before any code

Twenty-three acceptance criteria, each one something you can watch happen or watch fail. The commit history follows the spec's build order, test first. Revision 2 came from live testing: a number that clashes with a labelled fact now goes red and blocks Approve. Read SPEC.md

Run it yourself

uv run vouch starts the server with the sample loaded. MODEL=off works fully offline on the numeric layer. Set DEEPSEEK_API_KEY to check prose. uv run pytest and uv run python -m evals reproduce every number above.
